# Lowell Applied Research Group

Static website for [lowellappliedresearch.group](https://lowellappliedresearch.group), deployed with GitHub Pages.

## Preview locally

Run a static server from this directory, then open the displayed local URL:

```sh
python3 -m http.server 8080
```

## Publish

Push `main` to GitHub. The Pages workflow publishes the site automatically. In the repository settings, select **GitHub Actions** as the Pages source and set the custom domain to `lowellappliedresearch.group`.
